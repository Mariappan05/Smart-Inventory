IMPLEMENTATION APPROACH

- SearchableSelect now uses ModernDropdown internally

For pages with standard <select> elements:
1. Import ModernDropdown
2. Convert options to DropdownOption format
3. Replace <select> with <ModernDropdown>
4. Update onChange handlers

Example Conversion:
-------------------

OLD CODE:
<select
  value={form.storeId}
  onChange={(e) => setForm({ ...form, storeId: e.target.value })}
>
  <option value="">Select Store</option>
  {stores.map((store) => (
    <option key={store.id} value={store.id}>
      {store.name}
    </option>
  ))}
</select>

NEW CODE:
<ModernDropdown
  label="Store"
  required
  options={stores.map((store) => ({
    value: store.id,
    label: store.name,
    subtitle: `Code: ${store.code}`,
  }))}
  value={form.storeId}
  onChange={(value) => setForm({ ...form, storeId: value as string })}
  placeholder="Select store..."
  searchPlaceholder="Search stores..."
/>
