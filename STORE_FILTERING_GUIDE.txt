KEY PRINCIPLES:
---------------
1. Admin & Admin Manager: See ALL stores data
2. Other roles: See ONLY their assigned store data
3. When creating records: Auto-assign user's plantId if not provided
4. When listing records: Filter by plantId based on user role
5. Validation: Ensure users can only create/edit records for their store

HELPER FUNCTIONS:
-----------------
- canAccessAllStores(role): Returns true for ADMIN and ADMIN_MANAGER
- getStoreWhereClause(session): Returns {} for admin, {plantId: session.plantId} for others
- canUserAccessStore(session, plantId): Check if user can access specific store
