WORKFLOW IMPLEMENTATION
=======================

Step 1: Get User ID from Logged-in User
✅ JWT token contains userId (payload.sub)
✅ Available in session.userId

Step 2: Get Store ID from User
✅ JWT token contains plantId (payload.plantId)
✅ Available in session.plantId

Step 3: Save User ID and Store ID on Create
✅ createdById = session.userId
✅ plantId = session.plantId (or user's assigned store)

Step 4: Filter Data by Store ID
✅ WHERE plantId = session.plantId
✅ Admin/Admin Manager see all stores

QUERY EXAMPLES
==============

Query 1: Get Products Created by Specific User
```typescript
const products = await prisma.item.findMany({
  where: {
    createdById: userId,
    description: { startsWith: "PRODUCT_" }
  }
});
```

Query 2: Get Schedules Created by User's Store
```typescript
const schedules = await prisma.schedule.findMany({
  where: {
    plantId: session.plantId,
  },
  include: {
    createdBy: { select: { name: true } }
  }
});
```

Query 3: Get All Data Created by User
```typescript
const [products, tools, schedules] = await Promise.all([
  prisma.item.findMany({ where: { createdById: userId } }),
  prisma.tool.findMany({ where: { createdById: userId } }),
  prisma.schedule.findMany({ where: { createdById: userId } }),
]);
```
