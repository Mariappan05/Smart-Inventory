ACCESS CONTROL RULES
=====================

ADMIN & ADMIN_MANAGER:
- ✅ Can view ALL stores data
- ✅ Can create for ANY store
- ✅ Can manage ALL stores
- ✅ No filtering applied (plantId = undefined)

ALL OTHER ROLES:
- ✅ Can ONLY view their assigned store data
- ✅ Can ONLY create for their assigned store
- ✅ Cannot access other stores data
- ✅ Filtering applied (plantId = session.plantId)

4. Chennai users can see it

6. Admin can see it

Scenario 2: Madurai Store Manager Views Dashboard
--------------------------------------------------
1. User logs in → JWT token includes plantId = "madurai_id"
2. Dashboard loads → Filters all queries by plantId = "madurai_id"
3. Product count → Only Madurai products
4. Schedule count → Only Madurai schedules
5. Alert count → Only Madurai alerts
6. Recent activity → Only Madurai activity

Scenario 3: Admin Views Reports
--------------------------------
1. Admin logs in → JWT token has no plantId restriction
2. Admin generates report → No filtering applied
3. Report includes ALL stores data
4. Can see Chennai + Madurai + all other stores
