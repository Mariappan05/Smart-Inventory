HOW TO APPLY ACROSS ALL PAGES:
===============================

STEP 1: Import Date Formatting Functions
-----------------------------------------
Add this import to any component that displays dates:

import { formatDate, formatTime, formatDateTime } from "@/utils/dateTimeFormat";

STEP 2: Replace Date Display
-----------------------------
Replace any date display with formatted version:

BEFORE:
  {item.createdAt}
  {new Date(item.createdAt).toLocaleDateString()}

AFTER:
  {formatDate(item.createdAt)}
  {formatDateTime(item.createdAt)}  // if you need time too

STEP 3: Replace Dropdowns with SearchableSelect
------------------------------------------------
Replace standard select elements with SearchableSelect:

BEFORE:
  <select value={value} onChange={(e) => setValue(e.target.value)}>
    <option value="">Select...</option>
    {items.map(item => (
      <option key={item.id} value={item.id}>{item.name}</option>
    ))}
  </select>

AFTER:
  import { SearchableSelect } from "@/components/ui/SearchableSelect";

  const options = items.map(item => ({
    value: item.id,
    label: item.name,
    subtitle: item.code || item.description  // optional
  }));

  <SearchableSelect
    label="Select Item"
    required
    options={options}
    value={value}
    onChange={setValue}
    placeholder="Select an item..."
    searchPlaceholder="Search items..."
  />
