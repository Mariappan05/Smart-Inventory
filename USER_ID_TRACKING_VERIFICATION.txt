STORE ID MAPPING
=================

Users are mapped to stores via:
- User.plantId → Plant.id

Products/Data are mapped to stores via:
- Product.plantId → Plant.id
- Schedule.plantId → Plant.id
- ProductOutLog.fromPlantId → Plant.id
- ProductInLog.toPlantId → Plant.id
- ProductMovementLog.fromPlantId/toPlantId → Plant.id

Status: ✅ IMPLEMENTED

User Session Extraction:
```typescript
// In API routes
const authResult = await requireAuth(request);
if (authResult instanceof NextResponse) return authResult;
const session = authResult;

// session contains:
// - userId: string
// - role: string
// - plantId: string | null
```

Store Filtering:
```typescript
// Determine plantId for filtering
const plantId = canAccessAllStores(session.role) 
  ? undefined 
  : session.plantId || undefined;

// Use in queries
const data = await prisma.model.findMany({
  where: {
    plantId, // Filters by store
  },
});
```

User ID Tracking:
```typescript
// When creating data

  data: {
    productId,
    fromPlantId: session.plantId,

    // ... other fields
  },
});
```
