MODERN DROPDOWN IMPLEMENTATION GUIDE
=====================================

This guide explains how to implement the new ModernDropdown component across the entire application.

COMPONENT LOCATION
------------------
- Main Component: src/components/ui/ModernDropdown.tsx
- Backward Compatible Wrapper: src/components/ui/SearchableSelect.tsx
- Usage Examples: src/components/ui/ModernDropdownExamples.tsx

✓ Modern clean design with black theme support

BASIC USAGE
-----------

import { ModernDropdown } from "@/components/ui/ModernDropdown";

// Single Select
<ModernDropdown
  label="Store"
  required
  options={storeOptions}
  value={selectedStore}
  onChange={(value) => setSelectedStore(value as string)}
  placeholder="Select a store..."
  searchPlaceholder="Search stores..."
/>

// Multiple Select
<ModernDropdown
  label="Users"
  mode="multiple"
  options={userOptions}
  value={selectedUsers}
  onChange={(value) => setSelectedUsers(value as string[])}
  placeholder="Select users..."
/>

OPTION FORMAT
-------------
const options = [
  {
    value: "1",                    // Required: Unique identifier
    label: "Store A",              // Required: Display text
    subtitle: "Code: ST-001",      // Optional: Secondary text
    disabled: false                // Optional: Disable this option
  }
];

PROPS REFERENCE
---------------

Data Props:
- options: DropdownOption[]        // Array of options
- value: string | string[]         // Selected value(s)
- onChange: (value) => void        // Change handler

Configuration Props:
- mode: "single" | "multiple"      // Selection mode (default: "single")
- placeholder: string              // Button placeholder text
- searchPlaceholder: string        // Search input placeholder
- emptyMessage: string             // Message when no options found

State Props:
- disabled: boolean                // Disable entire dropdown
- loading: boolean                 // Show loading spinner
- required: boolean                // Show required asterisk

Styling Props:
- label: string                    // Label text above dropdown
- className: string                // Additional CSS classes
- error: string                    // Error message below dropdown

Feature Props:
- searchable: boolean              // Enable/disable search (default: true)
- clearable: boolean               // Show clear button (default: true)
- maxHeight: string                // Max height of dropdown (default: "320px")

Callback Props:
- onSearch: (term) => void         // Called when user types in search
- onOpen: () => void               // Called when dropdown opens
- onClose: () => void              // Called when dropdown closes

COMMON PATTERNS
---------------

Pattern 1: Store-Based Component Filtering
-------------------------------------------
const [selectedStore, setSelectedStore] = useState("");
const [selectedComponent, setSelectedComponent] = useState("");
const [componentOptions, setComponentOptions] = useState([]);

useEffect(() => {
  if (selectedStore) {
    fetchComponentsForStore(selectedStore);
  } else {
    setComponentOptions([]);
    setSelectedComponent("");
  }
}, [selectedStore]);

<ModernDropdown
  label="Store"
  required
  options={storeOptions}
  value={selectedStore}
  onChange={(value) => setSelectedStore(value as string)}
  placeholder="Select store..."
/>

<ModernDropdown
  label="Component"

  options={componentOptions}
  value={selectedComponent}
  onChange={(value) => setSelectedComponent(value as string)}

Pattern 3: API Search with Debounce
------------------------------------
const [searchResults, setSearchResults] = useState([]);
const [loading, setLoading] = useState(false);

const handleSearch = async (searchTerm: string) => {
  if (!searchTerm) return;
  
  setLoading(true);
  try {
    const res = await fetch(`/api/items?search=${searchTerm}`);
    const data = await res.json();
    if (data.success) {
      const options = data.data.map((item: any) => ({
        value: item.id,
        label: item.name,
        subtitle: `Code: ${item.code}`,
      }));
      setSearchResults(options);
    }
  } catch (error) {
    console.error("Error:", error);
  } finally {
    setLoading(false);
  }
};

<ModernDropdown
  label="Search Items"
  loading={loading}
  options={searchResults}
  value={selectedItem}
  onChange={(value) => setSelectedItem(value as string)}
  onSearch={handleSearch}
  placeholder="Search items..."
/>

Pattern 4: Form Validation with Error
--------------------------------------
const [form, setForm] = useState({ storeId: "" });
const [errors, setErrors] = useState({ storeId: "" });

const handleSubmit = () => {
  const newErrors = { storeId: "" };
  
  if (!form.storeId) {
    newErrors.storeId = "Store is required";
  }
  
  setErrors(newErrors);
  
  if (!newErrors.storeId) {
    // Submit form
  }
};

<ModernDropdown
  label="Store"
  required
  options={storeOptions}
  value={form.storeId}
  onChange={(value) => {
    setForm({ ...form, storeId: value as string });
    setErrors({ ...errors, storeId: "" });
  }}
  error={errors.storeId}
  placeholder="Select store..."
/>

Desktop (> 1024px):

KEYBOARD SHORTCUTS
------------------

When dropdown is closed:
- Enter / Space / Arrow Down: Open dropdown

When dropdown is open:
- Arrow Down: Move to next option
- Arrow Up: Move to previous option
- Enter: Select highlighted option
- Escape: Close dropdown
- Tab: Close dropdown and move to next field

ACCESSIBILITY
-------------

PERFORMANCE TIPS
----------------

1. Use React.memo for option rendering with large datasets
2. Implement virtual scrolling for 1000+ options
3. Debounce API search calls (300ms recommended)
4. Cache fetched options when possible
5. Use loading state during API calls

TROUBLESHOOTING
---------------

Issue: Dropdown not opening
Solution: Check if disabled or loading prop is set

Issue: Options not filtering
Solution: Verify searchable prop is true (default)

Issue: Selected value not displaying
Solution: Ensure value matches an option's value property

Issue: Dropdown stays open
Solution: Check for JavaScript errors preventing close handler

Issue: Styling looks wrong
Solution: Verify Tailwind CSS is properly configured

Issue: API search not working
Solution: Check onSearch callback and ensure debouncing
