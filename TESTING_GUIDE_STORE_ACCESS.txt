STORE-BASED ACCESS CONTROL - TESTING GUIDE
==========================================

PREREQUISITES
-------------
1. Have at least 2 stores created (e.g., Chennai Store, Madurai Store)
2. Have users assigned to different stores:
   - Admin user (no store assignment or can access all)
   - Chennai Store Manager (assigned to Chennai)
   - Madurai Store Employee (assigned to Madurai)
3. Have sample data in each store:
   - Products/Machines
   - Schedules
   - Tools
   - Alerts
   - QR Scans

AUTOMATED API TESTS
====================

Test API-1: Products Endpoint
```bash
# Login as Chennai user, get token
curl -X GET http://localhost:3000/api/machines \
  -H "Cookie: smi_session={chennai_token}"
# Verify: Only Chennai products returned

# Login as Admin, get token
curl -X GET http://localhost:3000/api/machines \
  -H "Cookie: smi_session={admin_token}"
# Verify: All products returned
```

Test API-2: Schedules Endpoint
```bash
# Login as Madurai user
curl -X GET http://localhost:3000/api/schedules \
  -H "Cookie: smi_session={madurai_token}"
# Verify: Only Madurai schedules returned
```

Test API-3: Alerts Endpoint
```bash
# Login as Chennai user
curl -X GET http://localhost:3000/api/alerts \
  -H "Cookie: smi_session={chennai_token}"
# Verify: Only Chennai alerts returned
```

Test API-4: Reports Endpoint
```bash
# Login as Madurai user
curl -X GET "http://localhost:3000/api/reports?type=machines" \
  -H "Cookie: smi_session={madurai_token}"
```

EXPECTED RESULTS SUMMARY
========================

✓ Store users see ONLY their store data
✓ Store users can ONLY create for their store
✓ Store users CANNOT access other store data
✓ Admin/Admin Manager see ALL store data
✓ Admin/Admin Manager can manage ALL stores
✓ All counts and statistics filtered by store
✓ All reports filtered by store
✓ All exports filtered by store
✓ Movement logs show transfers involving user's store
✓ QR scans filtered by product's store

FAILURE INDICATORS
==================

❌ Store user sees data from another store
❌ Store user can access another store's product via API
❌ Store user can create data for another store
❌ Admin cannot see all store data
❌ Counts include data from other stores
❌ Reports include data from other stores
❌ Cross-store data leakage in any module
